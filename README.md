# npv-bot

Telegram-бот для расчёта NPV инвестиционного проекта добывающего сектора, запущенный на сервере Linux.

Бот считает NPV и срок окупаемости проекта. Ещё он сравнивает два варианта: запустить проект сейчас или подождать год, пока станет ясно, куда пошла цена сырья. Упрощённая версия модели реальных опционов.
Учебный проект для рубежного контроля.

## Команды

| Команда | Пример | Что делает |
|---|---|---|
| `/start`, `/help` | `/help` | список команд |
| `/npv` | `/npv 1000 200 0.12 10` | NPV: инвестиции, годовой поток, ставка в долях, срок в годах |
| `/payback` | `/payback 1000 200` | срок окупаемости в годах |
| `/delay` | `/delay 1000 200 0.12 10` | сравнение «запустить сейчас» и «подождать год» |
| `/projects` | `/projects` | учебные проекты, отсортированные по NPV |
| `/history` | `/history` | ваши последние 5 расчётов |
| `/log` | `/log` | последние 10 строк журнала |

Цифры в `/projects` условные, учебные. Это не данные реальных компаний.

## Запуск

1. Скачайте проект:
   ```
   git clone https://github.com/aidana112/telebotik.git
   cd npv-bot
   ```
2. Создайте виртуальное окружение и установите библиотеку:
   ```
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```
3. Получите токен у @BotFather, скопируйте шаблон и вставьте токен в `config.py`:
   ```
   cp config.example.py config.py
   nano config.py
   ```
4. Запустите бота из папки проекта:
   ```
   .venv/bin/python bot.py
   ```

Проверить формулы без Telegram: `python3 finance.py`.

## Файлы

- `bot.py` обработчики команд и запуск бота
- `finance.py` формулы, классы `Project` и `DelayedProject`, учебные проекты
- `validators.py` проверка ввода регулярными выражениями
- `storage.py` история расчётов `data/history.txt` и журнал `logs/bot.log`
- `config.example.py` шаблон для `config.py`, сам `config.py` в git не попадает
